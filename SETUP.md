# Setup: Claude Code connected to Tonpit over MCP

You need a Claude subscription (or one to whichever model you work with) and a Tonpit account with a verified email. You connect once; from then on Claude brings Tonpit's tools, its models and its production skills into every session.

## Claude

Connecting Claude is one click: open [tonpit.com/mcp](https://www.tonpit.com/mcp), choose Claude, press **Add to Claude**, and sign in to Tonpit when asked. (Claude's custom connectors need Claude Pro or higher.)

## Any other agent

The same page walks you through ChatGPT, Cursor, terminal agents and any other MCP client. Either way, you can always ask your agent to connect itself:

```
Add Tonpit's MCP server and set it up for yourself: https://www.tonpit.com/api/mcp
Then tell me how to sign in.
```

At sign-in you choose what the agent may do in your account: read and edit projects, generate media, write and voice scripts, build motion graphics, cut the timeline, export.

## What the connection can spend

A connected agent's work in the studio is free: editing, the timeline, animation written as code, music and sound effects. Generated footage, images and voice cost credits, the same as in the app (a credit is one cent). Exports come with a plan, three a month without one. You can cap what a connected agent spends each month, or disconnect it, in Settings under Agent access. Current prices: [tonpit.com/pricing](https://www.tonpit.com/pricing).

## Which model

Use a strong one. In the Jerv session, Fable 5.1 wrote the script and the concept; Opus 5.5 did most of the editing and animation, and is generally cheaper for that long, repetitive part of the work.

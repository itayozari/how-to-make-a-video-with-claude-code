# The finished ad

[`jerv-before-after.mp4`](jerv-before-after.mp4): the Jerv before/after ad, 25 seconds, 1920x1080, made in Tonpit with Claude Code. Sound on.

Two generated shots (Seedance 2.5), four motion pieces written as code, one narrator, one track from Tonpit's music library. How it was made: [the write-up on tonpit.com](https://www.tonpit.com/blog/how-do-i-make-a-video-with-claude-code).
